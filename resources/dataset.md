# Datasets

## 1. Chandrayaan Map Browse (ISRO)
**Link:** https://chmapbrowse.issdc.gov.in/
**Description:** ISRO's web interface for browsing and downloading Chandrayaan-2 orbiter imagery (OHRC, TMC-2, IIRS, DFSAR) by location/region. Primary source for source (moving) images.

## 2. LROC Homepage (image downloads + processing guides)
**Link:** https://lroc.im-ldi.com/
**Description:** Official Lunar Reconnaissance Orbiter Camera (LROC) site, hosted by Arizona State University. Provides access to NAC/WAC image downloads via links to the PDS archive, plus processing guides (e.g., LROC_NAC_Processing_Guide.pdf) explaining EDR vs CDR file formats and calibration.
**Note:** Download real image files via the linked PDS archive pages, not this URL directly, this is the portal/documentation hub.

## 3. LROC QuickMap
**Link:** https://quickmap.lroc.im-ldi.com/
**Description:** Interactive 2D/3D map interface for browsing LRO and other lunar mission data (LOLA, GRAIL, SELENE, Lunar Prospector). Lets you draw a region and search for LROC NAC images filtered by lighting/viewing geometry — useful for building your sun-angle-labeled dataset. Results link out to the PDS archive for actual EDR file downloads.

## 4. ISRO Chandrayaan-2 Payloads Page
**Link:** https://www.isro.gov.in/chandrayaan2-payloads.html
**Description:** Official ISRO page listing and describing all Chandrayaan-2 orbiter payloads (OHRC, TMC-2, IIRS, DFSAR, CLASS, etc.) — specs, resolution, purpose. Good reference for payload documentation/citations rather than a data download source.

## 5. Harvard Dataverse (DVN/WW3IH0) — ⚠️ NOT lunar
**Link:** https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/WW3IH0
**Description:** This is refined image geometry, maps, and mosaics from **Hayabusa2's ONC (Optical Navigation Camera) images of asteroid Ryugu** (Hirata et al., 2026, arXiv:2602.12554) a small-body dataset for cross-validation only, similar to how PWIFT validated on Ryugu-ONC to test generalization beyond the Moon.
